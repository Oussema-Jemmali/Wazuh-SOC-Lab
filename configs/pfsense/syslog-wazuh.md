# pfSense Syslog Integration with Wazuh

## Overview

pfSense was configured to forward HAProxy events to the Wazuh SIEM server using remote Syslog.

This allows Wazuh to collect and analyze HAProxy availability events such as backend server failures and recoveries.

## Configuration

pfSense:
- IP Address: 192.168.1.1
- Syslog Protocol: UDP
- Syslog Port: 514
- Facility: local0
- Level: info

Wazuh Server:
- IP Address: 192.168.1.100
- Syslog listener enabled on UDP port 514

## pfSense Configuration

Navigation:

Services → HAProxy → Settings

Enabled:
- HAProxy logging

Remote Syslog:

Host:
192.168.1.100

Facility:
local0

Level:
info

## Wazuh Syslog Receiver

The Wazuh Manager was configured to receive remote Syslog events:

<remote>
    <connection>syslog</connection>
    <port>514</port>
    <protocol>udp</protocol>
    <allowed-ips>192.168.1.0/24</allowed-ips>
</remote>

## Result

HAProxy events generated by pfSense are received by Wazuh and analyzed by custom detection rules.
